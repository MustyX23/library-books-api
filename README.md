# Library Books API

Малко REST API за водене на книгите в библиотека и на това кой ги е заел.

## За кого е?

За библиотекарите в **малки библиотеки** – училищна библиотека, читалище или библиотека в офис – и за **читателите**, които ги използват.

## Какъв проблем решава?

Малките библиотеки често водят книгите и заеманията на хартия или в Excel таблица. Така е трудно да се отговори на прости въпроси:

- *Имаме ли тази книга?* → търсене в каталога по заглавие или автор
- *На рафта ли е в момента?* → при всяка книга се вижда дали е заета
- *У кого е?* → името на читателя се пази заедно с книгата

Library Books API дава на библиотекаря едно място, където да управлява каталога и заеманията, а всяко приложение (уеб страница, мобилно приложение, Excel/Power Query) може да го използва през HTTP.

## Функционалности

| Метод | Endpoint | Какво прави | Тикет |
|-------|----------|-------------|-------|
| `POST` | `/books` | Добавя нова книга | KAN-6 |
| `GET` | `/books` | Списък с всички книги | KAN-7 |
| `GET` | `/books?q=orwell` | Търсене по заглавие или автор | KAN-11 |
| `GET` | `/books/{id}` | Преглед на една книга | KAN-8 |
| `PUT` | `/books/{id}` | Редакция на книга | KAN-9 |
| `DELETE` | `/books/{id}` | Изтриване на книга | KAN-10 |
| `POST` | `/books/{id}/borrow` | Отбелязва книга като заета | KAN-2 |
| `POST` | `/books/{id}/return` | Отбелязва книга като върната | KAN-12 |
| `GET` | `/health` | Проверка дали услугата работи | KAN-1 |

## Стартиране локално

Нужен е Python 3.12+ (разработено с 3.14).

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS / Linux
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Отворете http://127.0.0.1:8000/docs за интерактивната Swagger документация.

## Пример

```bash
curl -X POST http://127.0.0.1:8000/books -H "Content-Type: application/json" \
     -d '{"title": "1984", "author": "George Orwell", "year": 1949}'

curl -X POST http://127.0.0.1:8000/books/1/borrow -H "Content-Type: application/json" \
     -d '{"borrower": "Ivan"}'
```

## Уеб интерфейс

Много проста уеб страница се намира в `web/` (React + Vite + TypeScript).
Първо стартирайте API-то, след това:

```bash
cd web
npm install
npm run dev
```

Отворете http://localhost:5173. Адресът на API-то може да се смени чрез `VITE_API_URL`.

## Тестове

```bash
pytest
```

Тестовете се пускат автоматично и при всеки Pull Request чрез GitHub Actions (KAN-14).

## Структура на проекта

```
app/
  main.py      # FastAPI приложение и endpoint-и
  models.py    # Pydantic модели
  storage.py   # съхранение в паметта
tests/         # pytest тестове
web/           # уеб интерфейс (React + Vite + TypeScript)
```

За да остане проектът прост, данните се пазят в паметта и се изчистват при рестарт.

## Процес на работа

Работата се планира в Jira (проект **KAN**). Всеки тикет има собствен бранч, кръстен на ключа му (напр. `KAN-6-add-book`). Промените влизат в `main` само чрез Pull Request с ключа на тикета в заглавието.
